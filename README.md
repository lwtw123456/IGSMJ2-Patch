# IGSMJ2 Patch — 明星三缺一2002 现代化补丁

具体偏移、原字节、新字节都在 `patch.py` 里，`python patch.py` 会把清单打印出来。

## 成果

- **在现代系统上直接跑**：Windows 10 / 11 实测可用，不再要求光碟、不再被 16 位色全屏卡住，窗口与全屏都正常，`Alt+Enter` 随时切换。
- **修掉了一批影响游玩的老问题**：启动校验、全屏一闪被弹回桌面、标题栏乱码、MENU 面板按钮点不动 / 拖不动、对局中红色提示乱码、故事模式与冠軍爭霸进不去。
- **开箱即用**：修改好的游戏见 [Releases](../../releases)，下载即玩，不再依赖所谓的窗口化工具。

## 具体修了什么

| # | 症状 | 根因 | 处理 |
|---|------|------|------|
| 1 | 窗口没有最小化按钮 | 创建窗口时样式漏了 `WS_MINIMIZEBOX` | `0xC80000` → `0xCA0000` |
| 2 | 标题栏 / 任务栏标题乱码 | Big5 字节直接喂给 ANSI 接口 | 标题字符串改 GBK |
| 3 | 启动要求放光碟、序號校验 | 光碟场景 + 序號校验函数 | 跳过场景、校验恒真（两处必须成对改，否则 retry 死循环） |
| 4 | 全屏一闪被弹回桌面、再也进不去 | `SetDisplayMode` 用了 16bpp，现代驱动不支持 | 改 32bpp |
| 5 | 全屏画面右下被裁 | 切 `WS_POPUP` 后没重算边框 | 补 `SWP_FRAMECHANGED` |
| 6 | MENU 面板黄色按钮点不动、标题栏拖不动 | ① 双击消息被当成「没按下」 ② 一帧两条消息泵抢同一组鼠标标志 ③ 拖拽依赖被牌桌吃掉的 moved 标志 | 加「按下锁存」、菜单改读锁存、拖拽每帧跟随 |
| 7 | 对局中右侧红色提示乱码 | 提示串是 Big5，经 GDI（系统 ANSI = GBK）渲染 | 消息表 36 条原地转 GBK |
| 8 | 故事模式 / 冠軍爭霸 点了进不去 | 进入前有 150 / 100 点数门槛，未达标只挂 1 个子项，点击被守卫跳过 | 两条 `jge` 改 `jmp`，门槛归零 |
